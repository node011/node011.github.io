# Red Team Operator — Resume / Portfolio

**Live site:** https://node011.github.io

A single-file, dark terminal/cyberpunk résumé site for a **Red Team Operator / Offensive Security Researcher**.
Everything (HTML, CSS, JS) lives in `index.html` — no build step, no dependencies, no framework.

## Features

- Dark cyberpunk aesthetic with neon green `#00ff41` and electric blue `#00d4ff`
- HTB-style animated network graph background (nodes, connections, packet flow)
- Hexagonal lattice drift overlay
- CRT scanline effect
- Typing animation on hero tagline
- Responsive design (mobile-friendly)
- Scroll-triggered reveals
- Print stylesheet (Cmd+P → Save as PDF)

## Sections

- Hero (name, title, stats)
- About (`whoami`)
- Skills (Network, Web, Cloud/K8s, Tools)
- Experience (6 roles)
- Education
- Certifications (3 certs)
- Contact (GitHub, LinkedIn, Medium, Email, PGP)

## Customising

Open `index.html` and edit in place. Landmarks are marked with comment banners like
`<!-- ==================== SKILLS ==================== -->`.

> The experience and certification content is real. Replace placeholder stats if needed.
